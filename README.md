# GitHub Followers

La aplicación utiliza la API de GitHub para optimizar la exploración de usuarios y el análisis de seguidores. Este proyecto está diseñado para proporcionar a los usuarios una descripción estadística de los perfiles de GitHub, descubriendo tanto a los usuarios individuales como a sus seguidores.

## Características técnicas

**Arquitectura MVC**<br/>Organización estricta del proyecto para un código modular y mantenible orientado al desarrollo escalable.

**UI 100% Programática**<br/>Interfaz construida por código, sin Storyboards — diseño responsive y totalmente personalizable mediante Auto Layout nativo.

**Diffable Data Source**<br/>Actualizaciones instantáneas y animadas de la vista al cambiar los datos, mejorando la respuesta de la interfaz.

**Decodificación JSON**<br/>Conectividad con la API y parseo JSON para un procesamiento y gestión de datos eficientes.

**Gestor de Persistencia**<br/>Habilita la función "Guardar en favoritos", permitiendo almacenar y recuperar contenido preferido sin conexión.

**Caché de Imágenes y Paginación**<br/>Flujo de trabajo optimizado y rendimiento mejorado para una mejor experiencia de usuario.

**Barra de Búsqueda Dinámica**<br/>Búsqueda en tiempo real que permite localizar contenido de forma eficiente, mejorando la usabilidad general.

**Errores, Alertas y Vistas Personalizadas**<br/>Alertas de error específicas y vistas de estado vacío contribuyen a una experiencia de usuario fluida e intuitiva.

**Reconocimiento de Gestos**<br/>Interacción y navegación intuitivas, con optimización del espacio en pantalla.
